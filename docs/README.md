# 开发文档 / 系统重构参考

本目录是**智能文档审核工作台**当前系统（Python FastAPI + Vue 3）的完整开发文档，用于后期系统重构。

## 重构目标（已确认）

| 项 | 决策 |
|----|------|
| **OCR 服务** | 保留 Python 项目，收敛为**纯 OCR / 文本抽取微服务**，对外暴露 HTTP API |
| **业务系统** | 用 **.NET Web 项目**重写（API + 业务编排 + LLM 调用 + DB 访问） |
| **前端** | 本轮**先规划后端**，前端（Vue 3）暂不动，只需保持 API 契约 |
| **数据库** | **保留 PostgreSQL**，.NET 用 EF Core / Npgsql 接入，表结构基本不变 |
